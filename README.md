# Outdoor Safety · Sea-to-Sky

A simple public website with checklists, “what to do if…” guides, common mistakes, and emergency numbers for outdoor trips in British Columbia’s Sea-to-Sky corridor.

## Turn the website on

1. Open https://github.com/lzl462/outdoorsafety/settings/pages
2. Under **Build and deployment**, set **Source** to **Deploy from a branch** (not GitHub Actions).
3. Branch: **main**. Folder: **/ (root)**.
4. Click **Save**.
5. Wait about one minute, then open https://lzl462.github.io/outdoorsafety/

## Local preview

```bash
python3 -m http.server 8080
```

Then visit http://localhost:8080
