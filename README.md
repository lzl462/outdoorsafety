# Outdoor Safety · Sea-to-Sky

A simple public website with checklists, “what to do if…” guides, common mistakes, and emergency numbers for outdoor trips in British Columbia’s Sea-to-Sky corridor (Howe Sound, Squamish, Whistler, Pemberton).

The site is English-language and meant for visitors and locals heading into the mountains.

## Live site

After GitHub Pages is switched on: https://lzl462.github.io/outdoorsafety/

**Turn the website on (one click):** open [Settings → Pages](https://github.com/lzl462/outdoorsafety/settings/pages), set **Source** to **GitHub Actions**, and save. The next deploy publishes the site.

## What is on the site

- Outdoor activities and local risk notes
- Interactive packing / trip checklists
- Printable cards (hike, winter, trip plan, lost, injured, emergency numbers)
- What to do if you are lost, hurt, in avalanche terrain, on the water, or without a phone
- Common mistakes that lead to Search and Rescue calls
- 9-1-1 and local emergency contacts
- QR code that opens this site

This is an educational project. It is **not** an official SAR, RCMP, or government website. In an emergency call **9-1-1**. Rescue in B.C. is free.
