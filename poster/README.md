# Large trifold project display — production brief

`trifold-sketch-2026-11-25.png` is Liz's hand sketch of the large trifold poster board for the presentation. It is a layout idea only, not final.

Layout in the sketch:
- Left panel: two picture or text boxes.
- Centre panel: a headline at the top, one large box below it, two smaller boxes in the middle, and a bottom row with the website QR code, a short "what the website is about" text box, and the Instagram QR code.
- Right panel: two picture or text boxes.

The final content and print layout are still to be made. The board should explain the whole project as well as advertise the website; use the [presentation](../presentation.html) and [approved-proposal comparison](../docs/school/README.md) as its content sources. The existing [website safety-poster layout](../pdfs/trifold.html) is a reference, not the completed large project display.

## Remaining production work

1. Confirm the actual board's overall dimensions, each panel width and the fold/gutter margins. No final measurements have been supplied.
2. Choose the text, pictures and screenshots for the boxes, with readable type for people standing at the table. Include Liz's project story and learning alongside the website features.
3. Build the full-size layout from those dimensions. Export a print master; if the chosen printer needs separate sheets or panels, prepare those files at the correct scale.
4. Arrange printing through the available school, print shop or other chosen route, then trim, mount and assemble the board. Printing/assembly are remaining deliverables, not completed work inferred from the sketch.
5. Confirm the finished board is ready for the presentation. The earlier exclusion of separate physical-printer tests remains; this production task does not reopen that test requirement.
