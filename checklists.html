Before you leave

Fill in the trip plan and leave it with someone you trust.

  • Trip plan
    For any trip. Fill in the lines. A second page says “For this trip, I need” and has blank lines. Not a full gear list.
    Download / print PDF
  • Hiking trip plan
    The same lines. Call 9-1-1 comes before “Things you might need.” A second page says “For this hike, I need” and has blank lines. Not a full gear list.
    Download / print PDF
  • Biking trip plan
    The same lines. A second page says “For this ride, I need” and has blank lines. Not a full gear list.
    Download / print PDF
  • Climbing trip plan
    The same lines. A second page says “For this climb, I need” and has blank lines. This sheet does not list ropes or a helmet.
    Download / print PDF

This is not an official rescue site. In an emergency, call 9-1-1.
